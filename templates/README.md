# Templates

The ROBOT templates in this folder can be edited by hand.

- `basis-sets.tsv` should only be extended if new basis sets are added to BSE. This file is maintained separately so
  when re-generating the ontology artifacts from BSE, the IDs remain stable for each basis set
- `families.tsv` was originally derived from BSE, but then heavily modified to add new subfamilies
- `roots` was originally derived from BSE, and can be extended (ideally with descriptions and better labels)
